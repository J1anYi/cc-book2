# Requirements Archive — v0.1 初始版本

**Milestone:** v0.1 初始版本
**Shipped:** 2026-04-29

---

## v1 Requirements — ALL COMPLETE

### 书籍上传 (UPLOAD)

- [x] **UPLOAD-01**: 用户可以上传 EPUB 格式的书籍文件 — ✅ Validated
- [x] **UPLOAD-02**: 用户可以上传 PDF 格式的书籍文件 — ✅ Validated
- [x] **UPLOAD-03**: 用户可以上传 TXT 格式的书籍文件 — ✅ Validated
- [x] **UPLOAD-04**: 系统自动提取书籍元数据（标题、作者、封面） — ⚠️ Partial (元数据提取部分格式支持)
- [x] **UPLOAD-05**: 上传的书籍保存到 data 目录 — ✅ Validated

### 书籍管理 (MANAGE)

- [x] **MANAGE-01**: 用户可以查看书库列表 — ✅ Validated
- [x] **MANAGE-02**: 用户可以搜索书籍（按标题/作者） — ✅ Validated
- [x] **MANAGE-03**: 用户可以删除书籍 — ✅ Validated
- [x] **MANAGE-04**: 用户可以为书籍添加分类/标签 — ✅ Validated
- [x] **MANAGE-05**: 管理后台有简单密码认证 — ✅ Validated

### 在线阅读 (READ)

- [x] **READ-01**: 用户可以在浏览器中打开并阅读 EPUB 书籍 — ✅ Validated
- [x] **READ-02**: 用户可以在浏览器中打开并阅读 PDF 书籍 — ✅ Validated
- [x] **READ-03**: 用户可以在浏览器中打开并阅读 TXT 书籍 — ✅ Validated
- [x] **READ-04**: 阅读器支持翻页功能（上一页/下一页/跳转） — ✅ Validated
- [x] **READ-05**: 系统自动保存阅读进度 — ✅ Validated
- [x] **READ-06**: 用户可以添加书签 — ✅ Validated
- [x] **READ-07**: 用户可以添加笔记/标注 — ✅ Validated

### 前后端架构 (ARCH)

- [x] **ARCH-01**: 前端 Vue3 + Vite + TypeScript 独立项目 — ✅ Validated
- [x] **ARCH-02**: 后端 Express + TypeScript REST API — ✅ Validated
- [x] **ARCH-03**: SQLite 数据库存储书籍元数据和用户数据 — ✅ Validated
- [x] **ARCH-04**: 前后端分离部署 — ✅ Validated
