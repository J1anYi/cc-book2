## Bug Fixes (Post-Phase)

### Bug 1: 管理页面重定向问题
- **Cause:** Route guard checking adminToken, redirecting when missing
- **Fix:** Removed meta: { requiresAuth: true } and simplified route guard

### Bug 2: EPUB文件加载404
- **Cause:** Files API expected filename but received book ID
- **Fix:** Modified files.ts to query database for file_path by book ID

### Bug 3: EPUB内部文件404 (META-INF/container.xml)
- **Cause:** epubjs trying to access internal EPUB paths via server
- **Fix:** Changed EpubReader to use ArrayBuffer instead of URL

### Bug 4: EPUB翻页按钮禁用
- **Cause:** location.start was CFI string, not object with index
- **Fix:** Use location.index directly for chapter position

### Bug 5: EPUB章节导航页码不更新
- **Cause:** prev()/next() was scrolling within chapter, not changing chapter
- **Fix:** Changed to chapter navigation mode with spine.get() and display()

## Lessons Learned

1. **epubjs locationChanged event:** location 对象结构需要通过 console.log 确认，不要假设结构
2. **文件服务设计:** 使用 ID 而非 filename 更安全，避免路径遍历
3. **Vue Router 导航:** click 比 goto 更适合 SPA，保持状态
4. **浏览器测试:** playwright-cli 是快速发现和验证 bug 的有效工具
