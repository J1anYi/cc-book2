# Requirements Archive — v0.3 阅读器入口与书籍信息展示

## v0.3 Requirements

### 书库首页 (LIBRARY)

- [x] **LIBRARY-01**: 用户访问首页时看到书库页面（而非上传页面）
- [x] **LIBRARY-02**: 书库页面以卡片形式展示所有已上传书籍
- [x] **LIBRARY-03**: 每张书籍卡片显示封面、标题、作者、文件类型
- [x] **LIBRARY-04**: 书籍卡片显示阅读进度百分比
- [x] **LIBRARY-05**: 用户可以按分类筛选书籍
- [x] **LIBRARY-06**: 用户可以搜索书籍（标题、作者）

### 阅读入口 (READER)

- [x] **READER-01**: 用户点击书籍卡片可直接进入阅读器
- [x] **READER-02**: 书库首页显示"继续阅读"区域，展示最近阅读的书籍
- [x] **READER-03**: 点击"继续阅读"书籍，自动跳转到上次阅读位置
- [x] **READER-04**: 阅读器页面有明确的返回书库按钮

### 书籍详情 (DETAILS)

- [x] **DETAILS-01**: 用户可从书籍卡片进入书籍详情页
- [x] **DETAILS-02**: 详情页显示书籍完整元数据（标题、作者、分类、标签、上传时间）
- [x] **DETAILS-03**: 详情页显示阅读进度和时间
- [x] **DETAILS-04**: 详情页提供"开始阅读"或"继续阅读"按钮
- [x] **DETAILS-05**: 详情页可以编辑书籍信息（分类、标签）

### 上传入口 (UPLOAD)

- [x] **UPLOAD-01**: 上传功能从首页移至独立页面或导航入口
- [x] **UPLOAD-02**: 上传成功后显示书籍预览并可立即开始阅读
- [x] **UPLOAD-03**: 导航栏清晰展示：书库、上传、管理
