## Lessons Learned

1. **CSS Variables 优先:** 所有样式统一使用设计系统变量，便于维护和未来扩展
2. **响应式断点:** 768px 和 480px 是合适的断点
3. **渐变使用:** 主色→辅色渐变适合进度条，纯色渐变适合封面占位
4. **动画克制:** 使用 transform 和 opacity，避免影响性能
